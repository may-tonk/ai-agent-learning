# 星河科技 员工费用报销制度（2026 版）

## P1 通用规则
P1.1 每一笔费用都必须有合规发票（报销单中 has_invoice 为 true）。没有发票的费用不予报销。
P1.2 费用必须在发生之日起 60 天内提交报销。用报销单的提交日期减去费用日期，差值大于 60 天的费用不予报销。
P1.3 报销币种为人民币，金额保留两位小数。
P1.4 一张报销单的核定总额（所有通过和核减后的金额之和，不含待人工复核的费用）超过 5000 元时，整张报销单需要财务复核，审核结论为 needs_review。

## P2 住宿
P2.1 住宿标准按"每晚"计算：一线城市（北京、上海、广州、深圳）每晚 600 元，其他城市每晚 400 元。
P2.2 住宿费超出标准的部分由员工自理：标准以内的部分正常报销，超出部分核减。
P2.3 住宿晚数 = 离店日期 − 入住日期。例如 10 月 8 日入住、10 月 10 日离店，是 2 晚。

## P3 餐饮
P3.1 出差餐补：每人每天上限 150 元，按出差天数计算。出差天数 = 返程日期 − 出发日期 + 1。整个行程的餐饮费合计超过"出差天数 × 150 元"的部分核减。
P3.2 业务招待：说明中必须写明客户单位名称和总参与人数（含我方人员），缺少任何一项的招待费不予报销。人均金额 = 招待费 ÷ 总参与人数。人均不超过 300 元的正常报销；人均超过 300 元的不自动核减，标记为待人工复核（需部门总监审批）。
P3.3 内部聚餐、团建餐费不属于业务招待，不予报销。

## P4 交通
P4.1 飞机限经济舱，火车限高铁/动车二等座。乘坐更高舱位或座席的，按同班次经济舱（或二等座）价格报销，差价核减；说明中没有写明经济舱（或二等座）价格的，该笔费用不予报销。
P4.2 市内出租车、网约车单次超过 200 元的，说明中必须写明用车原因，没有写明原因的不予报销。单次 200 元以内的无需说明原因。

## P5 不予报销的费用
P5.1 以下费用一律不予报销：交通违章罚款、个人娱乐消费（如 KTV、按摩、游戏）、个人物品购买。

## P6 审核结论的确定方式
P6.1 每一笔费用的状态只有四种：approved（全额通过）、adjusted（核减后通过）、rejected（不予报销）、pending（待人工复核，不计入核定总额）。
P6.2 整张报销单的结论按以下顺序确定：
- 有任何一笔 pending，或者触发 P1.4 → needs_review
- 否则，核定总额为 0 → reject
- 否则，有任何一笔 adjusted 或 rejected → partial
- 否则 → approve
